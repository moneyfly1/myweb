# 国际支付配置说明（Stripe / PayPal / USDT）

> 适用于有海外用户或希望支持国际支付的运营场景。三种支付方式在后台「支付配置」中新增，与支付宝/微信/易支付/码支付并行，互不影响。

## 一、Stripe 信用卡

Stripe 是国际主流信用卡收单服务，支持 Visa / Mastercard / American Express 等，按交易额抽成。适合面向海外用户收款。

### 1. Stripe 商户侧配置

1. 注册并登录 [Stripe Dashboard](https://dashboard.stripe.com/)（需海外主体/银行卡）。
2. 进入 **Developers → API keys**，复制：
   - **Secret Key**（形如 `sk_live_...`，测试环境为 `sk_test_...`）
3. 进入 **Developers → Webhooks**，点击 **Add endpoint**：
   - **Endpoint URL**：`https://你的域名/api/v1/payment/notify/stripe`
   - **Events**：勾选 `checkout.session.completed`
   - 创建后复制 **Signing secret**（形如 `whsec_...`）

### 2. 系统后台配置

登录管理员后台 → **支付配置** → 新增 → 支付类型选「Stripe 信用卡」：

| 字段 | 说明 |
|------|------|
| Secret Key | Stripe Dashboard 的 Secret Key |
| Webhook Secret | Stripe Webhook 的 Signing secret |
| 异步回调地址 | `https://你的域名/api/v1/payment/notify/stripe`（与 Stripe 后台一致） |
| 同步回调地址 | `https://你的域名/payment/return`（可选） |

> 💡 订单金额以 **USD（美元）** 计价。人民币金额会按当日汇率转换为美元后发起支付，最终以 Stripe 账单为准。

### 3. 验证

- 用 `sk_test_` 测试密钥 + Stripe 测试卡 `4242 4242 4242 4242` 可完成沙箱支付验证。
- 支付成功后 Stripe Webhook 回调 `/payment/notify/stripe`，订单自动标记已支付。

## 二、PayPal

PayPal 是国际主流支付方式，支持账户余额与绑定银行卡。

### 1. PayPal 商户侧配置

1. 注册 [PayPal Developer](https://developer.paypal.com/)（或使用商家账户登录）。
2. 进入 **Apps & Credentials**，创建 REST API 应用，获取：
   - **Client ID**（形如 `Ae...`）
   - **Secret**（形如 `EJ...`）
3. 进入 **Webhooks** → **Add Webhook**：
   - **Webhook URL**：`https://你的域名/api/v1/payment/notify/paypal`
   - **Event types**：勾选 `PAYMENT.CAPTURE.COMPLETED`
   - 创建后复制 **Webhook ID**

### 2. 系统后台配置

登录管理员后台 → **支付配置** → 新增 → 支付类型选「PayPal」：

| 字段 | 说明 |
|------|------|
| Client ID | PayPal REST API 应用 Client ID |
| Secret | PayPal REST API 应用 Secret |
| Webhook ID | PayPal Webhook 的 ID |
| 异步回调地址 | `https://你的域名/api/v1/payment/notify/paypal`（与 PayPal 后台一致） |
| 沙箱模式 | 开启后使用 PayPal 沙箱环境测试 |

> 💡 订单金额以 **USD（美元）** 计价。

### 3. 验证

- 开启「沙箱模式」并用 PayPal 沙箱账号（developer.paypal.com → Sandbox → Accounts 可创建）测试。
- 支付成功 PayPal Webhook 回调，订单自动标记已支付。

## 三、USDT 加密货币

USDT 是稳定币（1 USDT ≈ 1 USD），支持 TRC20 / ERC20 / BEP20 网络，适合无法接入传统支付或面向币圈用户的场景。

### 1. 准备钱包

- 准备一个 **USDT 收款地址**（TRC20 推荐，手续费低、确认快）。
- 系统仅展示地址与金额，用户转账后由管理员在订单中核对确认（半自动流程）。

### 2. 系统后台配置

登录管理员后台 → **支付配置** → 新增 → 支付类型选「USDT 加密货币」：

| 字段 | 说明 |
|------|------|
| 钱包地址 | 你的 USDT 收款地址（TRC20/ERC20/BEP20 均可） |
| 网络 | 选择 TRC20 / ERC20 / BEP20 |
| 确认数 | 区块链确认数要求（TRC20 建议 1） |

### 3. 用户支付流程

1. 用户选择 USDT 支付 → 页面展示**钱包地址 + 金额 + 过期时间**（30 分钟）。
2. 用户从自己的钱包转账对应金额 USDT 到该地址。
3. 管理员在订单管理中将该订单标记为已支付（系统提供手动确认入口）。

> ⚠️ USDT 为**半自动**流程：系统不自动监听链上转账，需要管理员确认到账后手动标记。适合小规模运营；如需全自动请接入 TRON/以太坊节点监听。

## 四、注意事项

| 事项 | 说明 |
|------|------|
| 币种 | Stripe / PayPal 以 USD 计价；USDT 以 USDT 计价。人民币订单会按系统汇率转换 |
| Webhook 安全 | 三种方式均校验签名（Stripe HMAC / PayPal verify API），伪造回调会被拒绝 |
| 多支付并行 | 三种国际支付可与支付宝/微信/易支付/码支付同时启用，用户端按列表展示 |
| 汇率 | 当前为系统内置汇率换算，如需实时汇率可自行对接汇率 API |

## 五、常见问题

| 问题 | 解决 |
|------|------|
| Stripe 报 `Invalid API Key` | Secret Key 填错或使用已吊销的 key；确认是 `sk_live_`/`sk_test_` 开头 |
| Stripe 回调 400 签名失败 | Webhook Secret 填错，或 Stripe 后台 Webhook 事件未选 `checkout.session.completed` |
| PayPal 报 `invalid_client` | Client ID / Secret 填错，或沙箱/生产模式不匹配 |
| PayPal 回调未生效 | Webhook ID 填错，或 PayPal 后台 Webhook URL 与系统不一致 |
| USDT 用户说转了但没到账 | 核对钱包地址/网络是否一致；确认区块链确认数已达成；检查 Memo（如有） |
