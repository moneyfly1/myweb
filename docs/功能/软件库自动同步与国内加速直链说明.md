# 软件库自动同步 + 国内加速直链（功能说明）

> 目标：让**国内用户快速下载**各客户端软件安装包。
> 方案：GitHub Releases 检测最新版本 → 用户点击下载时 302 直链到**国内 GitHub 加速镜像**（ghfast.top 等），
> 用户直接连国内镜像下载，速度快、无需网盘、无内容审核、不占 VPS 带宽。

## 一、为什么不用网盘

实测结论（2026-08）：

| 方案 | 结果 |
|---|---|
| 123 云盘 | 海外 VPS 登录触发风控（7012），token 绑定 IP |
| 阿里云盘 | 内部 API 直链需 Referer（无法浏览器 302 直连）；上传的安装包被**内容审核标记**（punish=2，取不到链接）；>100MB 文件也取不到链接；分享接口被新版拦截 |
| 夸克/坚果云/天翼等 | 要么和谐率高、要么无匿名直链、要么海外登录受限、要么有月流量限制 |

**GitHub + 国内加速镜像**（ghfast.top / gh-proxy.com / gh.llkk.cc / gh.ddlc.top）：
- 文件托管在 GitHub（本来就在），无审核、无大小限制
- 国内用户从国内镜像服务器下载（不经海外 VPS）→ 快
- 多镜像自动探测轮换，全挂时回退 GitHub 直连
- 零存储、零账号、零成本

## 二、工作方式

1. **版本检测**（定时，默认每 12 小时；也可手动「立即检测」）：
   遍历 7 款软件 × 各平台目标，查询 GitHub 最新 Release，匹配安装包资产
   （正则：Windows x64 / macOS Intel / macOS Apple / Android arm64-v8a 优先，非 fdroid 优先），
   记录最新版本号与资产名（`file_id_map`，兼容历史库分类名）。
2. **用户下载**（每次点击实时解析，30 分钟 Release 缓存）：
   `pan://<配置键>` → `/api/v1/download/gh?key=<配置键>` → GitHub 最新版 → 匹配资产
   → 探测可用镜像 → **302 直链**到 `https://ghfast.top/https://github.com/.../xxx.apk`。
   - 链接永远指向最新版；版本更新后无需人工改链接
   - 镜像可用性 5 分钟探测缓存，避免每个请求都打镜像
   - 200ms 全局限流防滥用
3. **手工自定义链接不受影响**：某个下载入口若配置了外部链接（非 `pan://`），检测与分发都会跳过。

## 三、后台操作

配置管理 → 软件下载配置 → 「GitHub 软件库自动同步」区域：

1. 设置「启用定时同步」与「同步间隔（小时）」→ 保存。
2. 点「立即同步」触发版本检测（页面显示实时进度：x/y 软件 · 检查中）。
3. 「版本对照」表显示每个目标 GitHub 最新版 vs 已检出版本：`已同步` / `待更新` / `待上传`。
4. 「查看上次同步报告」查看逐目标结果（成功/失败/跳过 + 安装包文件名）。

## 四、镜像前缀配置（可选）

默认镜像：`ghfast.top` → `gh-proxy.com` → `gh.llkk.cc` → `gh.ddlc.top` → 直连 GitHub。
如需调整，在 `system_configs`（category=software，key=`download_proxy_prefixes`）中配置，
每行一个前缀，`{url}` 表示占位（如 `https://ghfast.top/{url}`），`{url}` 单独一行表示直连。

## 五、实现文件

- `internal/services/software_sync/catalog.go` — 软件目录（配置键 → 仓库 → 平台/架构 → 正则）
- `internal/services/software_sync/sync.go` — 版本检测引擎、file_id_map、状态、进度
- `internal/services/ghrelease/release.go` — GitHub Releases 查询与资产匹配
- `internal/api/handlers/github_download.go` — `/download/gh` 直链解析（Release 缓存 + 镜像探测轮换）
- `internal/api/handlers/cloud.go` — 同步配置/触发/状态/版本对照接口
- `internal/services/scheduler/scheduler.go` — 定时版本检测
- `frontend/src/views/admin/Config.vue` — 同步面板（进度/报告/版本对照）
- `frontend/src/utils/githubDownload.js` — `resolvePanDownloadUrl`（pan:// → /download/gh）

## 六、接口

- `GET /api/v1/download/gh?key=<配置键>`（公共）— 302 到国内镜像直链
- `GET/POST /api/v1/admin/cloud/config` — 同步开关/间隔
- `POST /api/v1/admin/cloud/sync` — 触发版本检测（异步）
- `GET /api/v1/admin/cloud/sync/status` — 状态（运行中/进度/上次报告）
- `GET /api/v1/admin/cloud/versions` — 版本对照
- `GET /api/v1/software/versions`（公共）— 已检出版本信息，供下载页展示

## 七、注意事项

1. **镜像稳定性**：公共镜像可能随时变化（挂/限速），系统自动多镜像轮换 + 直连兜底；镜像列表可在配置中调整。
2. **GitHub API 限流**：未认证 60 次/小时；Release 缓存 30 分钟（7 仓库约每小时 14 次调用，安全）；
   配置 `backup_github_token`（category=backup）可提升到 5000 次/小时。
3. **国内速度**：取决于所选镜像与时段；ghfast.top 等通常几 MB/s 到几十 MB/s。
4. **无法直连 GitHub 的地区**：镜像本身位于国内/亚太，通常可用。
