# 工单管理功能说明

## 功能概述

工单管理功能用于处理用户提交的工单（客服工单），支持用户端提交工单和管理员端处理工单。工单系统提供了完整的客服支持流程，并支持在工单与回复中**上传图片、视频和附件**（含移动端相册选图）。

## 访问路径

- **管理员后台** → **工单中心**（`/admin/tickets`）
- **用户端** → **工单中心**（`/tickets`）

## 主要功能

### 1. 工单信息展示

- **管理端列表**：工单编号、标题、类型、状态、优先级、提交用户、**回复数**、创建时间、操作等。
- **用户端列表**：工单编号、标题、类型、状态、优先级、创建时间、**回复数**（可通过卡片/表格切换视图）。
- **筛选**：管理端支持按状态 / 类型 / 优先级筛选 + 关键词搜索；用户端支持按状态 / 类型筛选。

### 2. 工单创建（用户端）

用户可以创建新工单，填写**标题（必填）、类型（必填）、内容（必填）**，并可**附加文件**（可选）：

- 支持格式：图片（jpg/png/gif/webp/bmp/svg）、视频（mp4/mov/avi/mkv/webm/m4v）、音频（mp3/wav）、文档（pdf/doc/docx/xls/xlsx/ppt/pptx/txt/csv/log）、压缩包（zip/rar/7z）。
- 单文件上限 **30 MB**，一次最多 **9 个**。
- **移动端**提供两个入口：**「相册选图」**（`accept="image/*"`，iOS 弹出拍照/相册）与**「选择文件」**（视频/文档/压缩包走系统文件选择器）。
- 创建后附件归属工单本体（不与某条回复绑定）。

### 3. 工单处理（管理员端）

管理员可以查看工单、回复工单、**更新状态**（待处理→处理中→已解决→已关闭）、**添加内部备注**。管理员回复同样支持上传附件。

> 说明：管理员**不能修改优先级**；「关闭工单」是通过把状态置为 `closed` 实现。

### 4. 工单回复（用户端）

用户可以查看工单详情、管理员回复，并添加回复（可**仅上传附件而不输入文字**，也可图文/文附混排）。回复附件绑定到该条回复。

### 5. 附件展示（用户端 + 管理端）

工单详情中，工单本体与每条回复的附件都会展示：

- **图片**：缩略图，点击放大预览（支持多图轮播）。
- **视频**：内嵌播放器在线播放。
- **其他文件**：下载卡片（显示文件名与大小），点击下载/新窗口打开。

### 6. 通知联动

- 用户提交工单 / 用户回复 → 站内 + Telegram/Bark/邮件 通知管理员（通知内容含工单编号、标题与回复内容）。
- 管理员回复 → 站内通知 + 邮件通知工单所属用户（邮件含工单完整内容与回复历史）。

## 接口参考

- `POST /api/v1/tickets/` — 创建工单（body 可带 `attachments` 数组：`file_name / file_path / file_size / file_type`）
- `GET /api/v1/tickets/:id` — 工单详情（返回 `attachments`，含 `reply_id` 用于区分归属）
- `POST /api/v1/tickets/:id/replies` — 回复工单（可带 `attachments`）
- `POST /api/v1/tickets/upload` — **附件上传**（multipart，字段名 `file`；用户端/管理端登录后均可调用；返回 `url / file_name / file_size / file_type`）
- 管理端详情：`GET /api/v1/tickets/admin/:id`

附件文件通过 `/uploads/tickets/YYYYMM/...` 访问，由 Go 静态服务 + Nginx `location /uploads/` 反代提供。
