# 自建节点管理说明

## 概述

自建节点（Self-Hosted Nodes）是 CBoard 的特色功能：**在您自己的 VPS 上全自动部署代理节点**，无需手动配置，系统通过 SSH 自动安装 sing-box 并回传节点信息。支持远程管理、流量配额、证书自动续期。

## 访问路径

- **管理员后台** → **节点管理** → **自建节点**

---

## 二、搭建方式

### 方式一：VPS 全自动搭建（推荐）

1. 点击右上角 **「VPS自动搭建」**。
2. 填写：节点名称、VPS 的 **IP/SSH端口/root密码**（可选填域名）。
3. 有域名时选择多协议组合（自动申请 TLS 证书），无域名时自动只部署无需证书的协议（Reality 系列 + SS）。
4. 系统通过 SSH 自动部署 sing-box → 启动心跳 → 回传节点 → 完成。

### 方式二：手动搭建

1. 点击 **「手动搭建」**，输入节点名称与协议。
2. 系统生成一条安装命令。
3. 复制命令到 VPS 手动执行，节点自动回传。

### 已保存的 VPS（一键重新搭建）

搭建过的 VPS 会保存为档案（含 SSH 凭据、域名、协议列表），下次可**一键重新搭建**。列表默认折叠，点击展开。

> ⚠️ 如果 VPS 密码变了，点「编辑搭建」输入新密码后重新搭建。系统会先验证 SSH 凭据再重置节点——**密码错误时节点不受影响**。

---

## 三、远程管理功能

对已搭建的节点（有 SSH 凭据），支持以下远程操作：

| 操作 | 说明 |
|------|------|
| 查看远程状态 | 查询 sing-box 运行状态、监听端口、版本 |
| 重置节点 | 重新生成 UUID（所有协议共享） |
| 更改密码 | 修改 UUID |
| 更改端口 | 多协议随机分配互不重复端口 / 单协议指定端口 |
| 重新搭建 | 重置节点状态并远程重装 sing-box |
| 设置流量配额 | 节点级流量限制，超限自动屏蔽 |
| 清零流量 | 重置已用流量 |
| 更新 SSH 凭据 | 修改 VPS 登录信息 |

---

## 四、心跳与在线状态

- 节点每 **30 秒**向面板发送心跳（含流量增量）。
- 超过 **3 分钟**无心跳自动标记离线。
- 心跳恢复自动重新上线并启用。

---

## 五、流量配额自动屏蔽

- 设置配额后，节点用满配额自动禁用（`is_active=false`）。
- 支持**节点级**配额与**客户独享**配额（分配客户时可单独设配额）。
- 超限节点在管理后台标记，日志记录"流量配额超限"。

---

## 六、证书自动续期（关键）

自建节点使用 Let's Encrypt 证书（acme.sh 申请）。**部署脚本内置自动续期**：

1. 每次部署/重新搭建自动配置 acme.sh 自动续期定时任务。
2. 续期成功后自动把新证书复制到 sing-box 目录并重启服务。
3. 无需手动干预。

> 💡 证书到期前 30 天自动续期。若发现证书过期，在节点管理里重新搭建即可自动修复（脚本会先检查已有证书，再补装续期 hook）。

---

## 七、多协议共享设计

- 同一 VPS 上所有协议共享同一个 sing-box 实例。
- 各协议子节点记录挂在同一个 `install_id` 下，心跳、流量、状态同步更新。
- **UUID 共享**：修改密码/重置节点时，所有协议统一更新（保证订阅一致性）。

---

## 八、注意事项

| 事项 | 说明 |
|------|------|
| SSH 凭据加密 | VPS 密码用 `SECRET_KEY` 加密存储，`SECRET_KEY` 变更后需重新 update-ssh |
| VPS IP 变更 | 换 IP 后需更新节点 SSH 地址（update-ssh 或编辑搭建） |
| 磁盘空间 | 搭建/重装前确保 VPS 磁盘有足够空间，避免脚本写入失败 |
| 域名 DNS | 使用域名时需确保 DNS 已解析到 VPS 公网 IP，否则客户端无法连接 |
| 防火墙 | 需放行协议对应端口（443/8444/2055/8388 等） |
