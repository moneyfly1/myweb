# 123 云盘自动填充下载链接（功能说明）

> 解决"软件下载链接经常失效、每次都要手动去 123 云盘复制新链接回来填"的问题。
> 版本：v2 新增功能，后端 Go + 前端 Vue。

## 一、功能概览

在「配置管理 → 软件下载配置」页新增了 **123云盘自动填充** 面板，支持两种模式：

| 模式 | 填入的内容 | 用户点下载时 | 链接会不会失效 |
|---|---|---|---|
| **动态（推荐）** | 写入标记 `pan://<关键词>` | 后端实时向 123 云盘生成新链接再跳转 | **永不失效**，每次点击都是现取的 |
| **静态** | 写入当前有效的下载链接 | 直接用静态链接 | 会失效，失效后回后台再点一次"一键填充" |

**取链方式**：直链（`download_info`，已实测验证：无需 Referer、匿名可直接下载）。链接模式固定为"直链"（分享创建接口参数不稳定，已从面板移除）。

动态模式下，链接生成有 10 分钟内存缓存，不会每次点击都打 123 云盘接口。

## 二、配置步骤

1. 进入 **配置管理 → 软件下载配置**，滚动到「123云盘自动填充」区域。
2. 填写 123 云盘登录信息，**三选一**（优先级 Token > Cookie > 账号密码）：
   - **账号 + 密码**（推荐）：工具自动登录，token 失效自动重登，无需维护。
   - **Cookie**：从浏览器 DevTools 复制。注意网页版 API 的登录 token 存在名为 **`jwt`** 的
     HttpOnly cookie 里，`document.cookie` 复制不到，必须从 **DevTools → Application → Cookies →
     https://yun.123pan.cn** 里找到 `jwt` 那一行复制（连同其它 cookie 一起粘贴即可，工具会自动提取）。
   - **Token**：DevTools → Network 里任意 `b/api` 请求的 `Authorization: Bearer` 后面的值。
3. 点「保存云盘配置」，再点「测试连接」确认账号可用。
4. 在 **软件 ↔ 云盘文件名关键词** 表格里，为每个软件填写云盘里能搜到安装包的关键词
   （例如 `clash`、`v2rayN`、`hiddify`），可点「测试」查看云盘搜索结果确认。
5. 选择链接模式（默认"直链"，已验证可用），然后二选一点击：
   - **一键生成并填充（动态 · 实时解析）**：推荐。把所有软件的下载链接填成 `pan://关键词` 并保存，
     以后用户点击下载时后端自动生成最新链接。
   - **一键生成并填充（静态链接）**：把当前有效的下载链接直接填进配置。
6. 完成后点上方「保存软件配置」兜底保存（面板本身也会直接写库）。

## 三、混合映射（部分软件用云盘、部分用外部链接）

下载链接是**逐字段独立**的，13 个软件可以各用各的来源：

| 该软件下载来源 | 关键词表里怎么填 | 下载链接框里怎么填 | 用户点下载时 |
|---|---|---|---|
| 123 云盘 | 填关键词（如 `v2rayN`） | 一键生成后自动变成 `pan://v2rayN` | 实时生成云盘新链接 |
| 其他来源（官网 / App Store / GitHub 等） | **留空** | 手动填任意外部 URL | 直接用外部链接 |
| 未配置 | 留空 | 留空 | 走原有 GitHub Release 兜底 |

- 一键生成**只处理填了关键词的行**，留空的行跳过（结果报告会标注"未填写关键词，已跳过"），
  **不会覆盖**你手动填的外部链接。
- 面板关键词表新增"当前配置"列：`云盘动态`（pan://）/ `外部链接` / `未配置` 一目了然。
- 关键词尽量精确到平台，避免云盘里同名多平台文件搜错：例如 Windows 版填
  `clash-verge-windows`、macOS 版填 `clash-verge-macos`。

### 同一软件多平台/多版本（exe / dmg / apk）

云盘里同一款软件有多个平台的安装包时，用**扩展名过滤**精确锁定：

| 配置项 | 关键词 | 扩展名 | 说明 |
|---|---|---|---|
| `clash_verge_windows_url` | `clash-verge` | `exe` | 只匹配 .exe |
| `clash_verge_macos_url` | `clash-verge` | `dmg` | 只匹配 .dmg |
| `clash_android_url` | `clash-verge` | `apk` | 只匹配 .apk |

- 匹配规则：文件名以 `.<扩展名>` 结尾（大小写不敏感）。
- 多个版本（如 v1.2.3.exe / v1.4.0.exe）时**自动取最新**（按云盘更新时间排序）。
- "测试"按钮会带上当前行的扩展名过滤，可直接验证锁定的文件是否正确。
- 扩展名留空 = 不过滤，此时关键词需足够精确（如包含平台名），否则可能匹配到其它平台的文件。

## 四、用户端行为

- 配置为动态（`pan://...`）的软件：用户点击「下载」时，前端把 `pan://` 转成
  `/api/v1/download/pan?q=<关键词>`，后端实时搜索云盘 → 生成新链接 → 302 跳转下载。
- 配置为静态链接的软件：与旧行为完全一致。
- 未配置任何链接的软件：维持原有 GitHub Release 自动解析逻辑不变。

## 五、实现说明

### 后端

- `internal/services/pan123/pan123.go`：123 云盘客户端
  - 登录：`POST https://login.123pan.com/api/user/sign_in`（邮箱/手机号自适应），token 失败自动重登
  - 请求签名：复刻开源 alist 的 crc32 签名算法（时间戳 + 随机数 + 路径签名）
  - 搜索：`GET /b/api/file/list/new?event=searchFile&SearchData=<关键词>`
  - 直链：`POST /b/api/file/download_info`（OpenList 同款请求体，含 base64 params 兼容与
    带 `Referer: https://yun.123pan.com/` 的 302 跟随解析，拿到最终 CDN 地址）
  - 分享链接：`POST /b/api/share/create` + `POST /b/api/share/download/info`
  - 内置 700ms 请求限频 + `.com`/`.cn` 双域名自动切换
- `internal/api/handlers/pan123.go`：管理接口 + 动态解析接口
  - 管理接口（需管理员登录）：
    - `GET/POST /api/v1/admin/pan123/config` — 读取/保存配置（密码脱敏）
    - `POST /api/v1/admin/pan123/test` — 测试连接
    - `GET /api/v1/admin/pan123/search?keyword=` — 搜索云盘文件
    - `POST /api/v1/admin/pan123/refresh` — 一键搜索+生成+填充
  - 公共接口：
    - `GET /api/v1/download/pan?key=<配置键>|q=<关键词>` — 实时生成并 302 跳转（10 分钟缓存，
      复用现有 `/download/resolve` 的 URL 合法性/SSRF 校验）

### 前端

- `frontend/src/utils/api.js`：新增 `pan123API`
- `frontend/src/utils/githubDownload.js`：新增 `resolvePanDownloadUrl()`，识别 `pan://` 前缀
- `frontend/src/views/admin/Config.vue`：123云盘自动填充面板（配置、测试、关键词表、一键填充、结果报告）
- `frontend/src/views/Help.vue` / `Dashboard.vue` / `components/tutorials/SoftwareTutorials.vue`：
  下载时对配置链接做 `pan://` 转换

## 六、注意事项与限制

1. **分享链接有下载次数/速度限制**（123 云盘免费版机制，无法绕过）。
   动态模式的意义在于：链接达到限制失效后，下一个用户点击会自动重新生成，无需人工干预。
2. **分享密码（可选）**：如需给分享链接加密，在配置里填写"分享密码"，留空则生成无密码分享。
3. **风控**：网页版 API 有签名与频率限制，本工具已内置 700ms 请求间隔与 10 分钟链接缓存。
   若频繁触发验证码，请适当降低使用频率。
4. **凭证安全**：云盘密码明文存于 `system_configs`（与项目内其它配置一致）。如服务器被攻破，
   云盘密码会泄露，建议使用低频账号或定期更换密码。
5. **直链模式**（默认）已实测：生成的 CDN 链接无需 Referer，匿名浏览器可直接下载。
6. 一键填充会批量请求云盘接口（搜索+取链），受 123 云盘频率限制影响，全部 13 个软件约需十几秒。

## 八、GitHub 软件库自动同步（定时任务）

自动从 GitHub 拉取 **v2rayN / Hiddify / Clash Verge / Clash Part / V2rayNG / Clash Meta(Android)** 的最新版本，
下载安装包上传到你的 123 云盘并自动设置直链（`pan://<配置键>`）。

### 工作方式

- **版本比对**：每次同步先查 GitHub 最新 Release，与云盘已同步版本（存于 `pan123.file_id_map`）对比，
  **只有新版本才下载上传**，其余跳过，避免浪费流量。
- **替换并删除旧版**：检测到 GitHub 有新版本时，下载上传新安装包到云盘，**自动删除云盘中的旧版本文件**；
  无新版本时继续使用旧版本，不重复下载。
- **平台/架构全覆盖**：Windows x64、macOS Intel、macOS Apple 芯片（arm64）、Android APK（优先 arm64-v8a，优先非 fdroid 构建）。
- **取链**：直链按 fileId 实时生成（`pan://<配置键>` → 后端 `download/pan?key=` 直接取文件 ID 的直链），
  不再依赖关键词搜索，更精准。
- **定时**：默认每 12 小时检查一次（`sync_interval_hours` 可配 1–168），调度器每 10 分钟检查是否到期；
  也可在后台点「立即同步」手动触发。
- **不覆盖手工配置**：某个下载入口若是管理员手填的外部链接（非 `pan://`），同步不会覆盖它。

### 后台操作

配置管理 → 软件下载配置 → 「GitHub 软件库自动同步」区域：

1. 确认上方已保存 123 云盘登录信息（账号密码/cookie/token 任一）。
2. 设置「启用定时同步」开关与「同步间隔（小时）」→ 点「保存定时设置」。
3. 点「立即同步」——首次会下载上传全部 6 款软件（几十 MB 到几百 MB，耗时较长，页面会自动轮询状态）。
4. 「版本对照」表显示每个目标 GitHub 最新版 vs 云盘已同步版：`已同步` / `待更新` / `待上传`。

### 新增接口

- `POST /api/v1/admin/pan123/sync` — 触发同步（异步）
- `GET /api/v1/admin/pan123/sync/status` — 同步状态（运行中/上次结果/上传数量）
- `GET /api/v1/admin/pan123/versions` — GitHub 最新版 vs 云盘版本对照
- `GET /api/v1/software/versions`（公共）— 已同步版本信息，供下载页展示

### 实现文件

- `internal/services/pan123/upload.go` — 上传：`upload_request` → S3 预签名分片 PUT → `upload_complete/v2`
- `internal/services/ghrelease/release.go` — GitHub Releases 查询与下载（支持加速前缀）
- `internal/services/software_sync/catalog.go` — 软件目录（配置键 → 仓库 → 平台/架构 → 正则）
- `internal/services/software_sync/sync.go` — 同步引擎、file_id_map、状态
- `internal/services/scheduler/scheduler.go` — 定时任务（`syncSoftwareLibrary`）
- `internal/api/handlers/pan123.go` — 同步/版本接口；动态解析优先 fileId 直取

### 注意

- 首次同步上传体积大，受 123 云盘免费版上传速度/容量限制影响。
- 软件仓库如变更（如 Clash Meta 迁移仓库），在 `catalog.go` 中调整 `Repo` 即可。
- 定时同步仅在有新版本时下载上传，日常运行开销很小。
