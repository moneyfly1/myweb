# 阿里云盘自动填充下载链接（功能说明）

> 解决"软件下载链接经常失效、每次都要手动去网盘复制新链接回来填"的问题。
> 后端 Go + 前端 Vue。已从 123 云盘全面迁移到**阿里云盘**（Open API，OAuth refresh_token 认证）。

## 一、为什么用阿里云盘

| 对比项 | 123 云盘（已废弃） | 阿里云盘（当前） |
|---|---|---|
| 认证方式 | 账号密码/短信/二维码，token 绑定 IP | OAuth refresh_token，**不绑定 IP** |
| 海外服务器（本 VPS） | 密码登录触发 7012 风控、短信需滑块、微信扫码"用户不存在" | **无境外风控，海外服务器直接可用** |
| 链接模式 | 分享直链，有次数/速度限制 | Open API 实时生成下载链接（10 分钟缓存） |
| token 有效期 | 约 90 天 | 约 90 天，**测试连接时自动轮换**，无需人工更新 |

## 二、功能概览

- **动态直链（推荐）**：软件下载链接填成标记 `pan://<配置键>`，用户每次点击下载时，
  后端实时向阿里云盘 Open API 生成新下载链接再 302 跳转。**链接永不失效**。
- **GitHub 自动同步**：定时从 GitHub 拉取 7 款软件的最新版本，下载安装包上传到你的阿里云盘，
  自动设置为 `pan://<配置键>` 动态直链；**仅当 GitHub 有新版本时才下载上传**，并自动删除云盘旧版本。
- **不覆盖手工配置**：某个下载入口若是手填的外部链接（非 `pan://`），同步不会覆盖它。

## 三、配置步骤

1. 进入 **配置管理 → 软件下载配置**，滚动到「阿里云盘自动填充」区域。
2. 获取 refresh_token：浏览器登录 **www.alipan.com** → F12 → **Application → Local Storage →
   https://www.alipan.com** → 找到键名 **`token`**，复制其中 **`refresh_token`** 的值，粘贴到后台输入框。
3. **云盘上传目录（可选）**：点「**从云盘选择**」按钮直接浏览你的阿里云盘目录树，选中即自动填入
   （无需手填）；也可手填文件夹名（如 `软件下载`，支持 `软件/下载` 多级路径），
   留空则上传到网盘根目录。同步时会在该目录下**自动为每个软件创建子文件夹**
   （如 `软件下载/v2rayN/`、`软件下载/Hiddify/`），安装包按软件分别存放；目录不存在会自动创建。
4. 点「保存云盘配置」，再点「测试阿里云盘连接」——成功会显示目标目录及其文件数，
   若 token 将到期会自动轮换并回存新 token（无需再手动更新）。
5. （可选）在「GitHub 软件库自动同步」区域设置「启用定时同步」与「同步间隔（小时）」，点「保存定时设置」。
6. 点「立即同步」触发首次同步（会下载上传全部安装包，耗时较长，页面自动轮询状态）。
7. 「版本对照」表显示每个目标 GitHub 最新版 vs 云盘已同步版：`已同步` / `待更新` / `待上传`。

## 四、用户端行为

- 配置为动态（`pan://...`）的软件：用户点击「下载」时，前端把 `pan://` 转成
  `/api/v1/download/cloud?key=<配置键>`，后端实时生成阿里云盘直链 → 302 跳转下载。
- 配置为外部链接的软件：与旧行为完全一致，直接使用手填链接。
- 未配置任何链接的软件：维持原有 GitHub Release 自动解析逻辑不变。
- macOS 用户端按芯片架构（Intel / Apple）自动选择对应版本的下载入口。

## 五、GitHub 软件库自动同步（定时任务）

自动从 GitHub 拉取 **v2rayN / Hiddify / Clash Verge / Clash Part / V2rayNG / Clash Meta(Android) / FlClash**
的最新版本，下载安装包上传到你的阿里云盘并自动设置直链（`pan://<配置键>`）。

### 工作方式

- **版本比对**：每次同步先查 GitHub 最新 Release，与云盘已同步版本（存于 DB `pan123` 类目下的
  `file_id_map`，为兼容历史数据沿用旧分类名）对比，**只有新版本才下载上传**，其余跳过，避免浪费流量。
- **自愈**：即使版本号一致，同步前会校验云盘文件是否仍存在——若被手动删除会自动重新上传，无需人工干预。
- **token 自维护**：同步过程中若 refresh_token 到期会自动轮换，并把新 token 回存到数据库（约 90 天有效期，无需人工更新）。
- **替换并删除旧版**：检测到 GitHub 有新版本时，下载上传新安装包到云盘，**自动删除云盘中的旧版本文件**。
- **同名资产去重**：同一软件内同名安装包（如 Hiddify 官方 macOS 通用包，Intel/Apple 共用同一 dmg）只上传一次，两个下载入口共用同一文件。
- **平台/架构全覆盖**：Windows x64、macOS Intel、macOS Apple 芯片（arm64）、Android APK
  （优先 arm64-v8a，优先非 fdroid 构建）。
- **取链**：直链按文件 ID 实时生成（`pan://<配置键>` → 后端 `download/cloud?key=` 直接取文件 ID 直链），
  不依赖关键词搜索，更精准。
- **定时**：默认每 12 小时检查一次（`sync_interval_hours` 可配 1–168），调度器每 10 分钟检查是否到期。
- **上传实现**：阿里云盘 Open API 分片上传（20MB/片）：`create` → `getUploadUrl` → PUT 各分片 → `complete`；
  上传目录可配置（`aliyun_folder`，支持多级路径），并按软件自动建子文件夹（`EnsureFolder`/`EnsureDir`）。
- **直链**：`getDownloadUrl`（expire_sec 最长 4 小时）返回带签名直链，匿名可直接下载，
  与 123 云盘直链行为一致；后端缓存 10 分钟避免每次点击都打云盘接口。

### 后台接口

- `GET/POST /api/v1/admin/cloud/config` — 读取/保存阿里云盘配置（refresh_token 脱敏显示）
- `POST /api/v1/admin/cloud/aliyun/test` — 测试连接（自动轮换 refresh_token）
- `GET /api/v1/admin/cloud/aliyun/search` — 搜索云盘文件（管理端备用）
- `POST /api/v1/admin/cloud/sync` — 触发同步（异步）
- `GET /api/v1/admin/cloud/sync/status` — 同步状态（运行中/上次结果/上传数量）
- `GET /api/v1/admin/cloud/versions` — GitHub 最新版 vs 云盘版本对照
- `GET /api/v1/download/cloud?key=<配置键>`（公共）— 实时生成直链并 302 跳转（10 分钟缓存）
- `GET /api/v1/software/versions`（公共）— 已同步版本信息，供下载页展示

### 实现文件

- `internal/services/aliyundrive/aliyundrive.go` — 阿里云盘 Open API 客户端（token 刷新/列表/搜索/直链/分片上传/删除）
- `internal/services/ghrelease/release.go` — GitHub Releases 查询与下载（支持加速前缀、HTML 污染校验）
- `internal/services/software_sync/catalog.go` — 软件目录（配置键 → 仓库 → 平台/架构 → 正则）
- `internal/services/software_sync/sync.go` — 同步引擎（仅阿里云盘后端）、file_id_map、状态
- `internal/services/scheduler/scheduler.go` — 定时任务（`syncSoftwareLibrary`）
- `internal/api/handlers/cloud.go` — 云盘配置/测试/同步/版本接口；动态解析优先文件 ID 直取
- `frontend/src/views/admin/Config.vue` — 阿里云盘配置 + GitHub 同步面板
- `frontend/src/utils/api.js` / `githubDownload.js` — `cloudAPI`、`resolvePanDownloadUrl`（`pan://` → `/download/cloud`）

## 六、注意事项与限制

1. **refresh_token 有效期约 90 天**：测试连接 / 同步时若发现过期会自动轮换并回存，无需人工干预；
   若长时间未使用导致轮换失败，重新从浏览器复制粘贴即可（无需重新部署）。
2. **凭证安全**：refresh_token 明文存于 `system_configs`（与项目内其它配置一致）。
   阿里云盘 token 权限为账号全量，建议使用专门用于此用途的账号。
3. **首次同步体积大**：受阿里云盘上传速度与账号容量限制影响；日常增量同步开销很小。
4. **下载限速**：阿里云盘 Open API 直链无需 Referer、匿名可下载，但下载速度受阿里云盘官方策略影响。
5. **软件仓库变更**（如某仓库迁移）：在 `catalog.go` 中调整 `Repo` 即可。
